# Sources De L’identité Visuelle Oculox

Ce répertoire conserve les créations graphiques d’origine fournies pour Oculox.

- `logo_Oculox.png` : composition complète avec fond graphique ;
- `icone_Oculox.png` : écusson seul avec fond graphique.

Les interfaces Web utilisent une version transparente et optimisée située dans `docs/images/logo/logo_Oculox.png`. Le favicon carré dérivé de l’écusson se trouve dans `dev/branding/oculox-icon.png`.

Cette séparation évite d’alourdir les conteneurs avec les fichiers maîtres tout en conservant les sources nécessaires aux évolutions futures de l’identité visuelle.
